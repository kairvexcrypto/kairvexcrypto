# BlockJournal

Журнал изменений блоков для Paper 1.21.11 и Java 21.

[Репозиторий проекта](https://github.com/kairvexcrypto/BlockJournal)

Реализованы запись событий в SQLite, очередь вне игрового потока, поиск с фильтрами, проверка блоков инструментом, резервные пакеты и восстановление без дублей.

Версия 0.1.0 собрана; 24 автоматических теста пройдены. Проверка на живом сервере ещё не выполнена.
