# Ошибка Java: сверяем среду запуска

Если ошибка указывает на несовместимую версию Java или формат класса, сохраните её точный текст. Затем проверьте `java -version` именно в том окружении, которое запускает сервер. В панели, службе и интерактивной консоли могут использоваться разные исполняемые файлы.

Не выбирайте Java только по принципу «самая новая». Требования задают конкретные версии ядра и плагинов. Сверьте их документацию; если требования конфликтуют, потребуется совместимая сборка одного из компонентов.

После изменения среды выполните полный перезапуск и проверьте журнал с самого начала. Если сервер запускается через скрипт с абсолютным путём к Java, изменение системного значения по умолчанию может на него не повлиять.

**Проверка результата:** журнал подтверждает нужную Java, сервер и плагин загружаются вместе.

Документация для сверки требований: [Paper](https://docs.papermc.io/paper/).
