# Название предмета — плохой идентификатор

Название и описание нужны игроку, но их не стоит делать единственным признаком особого предмета. Название может измениться, а похожий предмет может появиться из другого источника.

В архитектуре плагина отделяйте отображение от идентификатора механики. Например, планируйте отдельный PDC-ключ и проверяйте его тип и допустимое значение. Для уникальных экземпляров нужен отдельный идентификатор экземпляра, а не только общий ID разновидности.

Наличие метки не решает все вопросы доверия: другие плагины и инструменты с доступом к данным тоже могут менять предметы. Права команд выдачи и обработка неизвестных значений остаются необходимыми.

**Проверка результата:** переименование не ломает настоящий предмет, обычный предмет с похожим названием не активирует способность, а неизвестный ID обрабатывается без исключения.
