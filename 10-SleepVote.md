# SleepVote

**Голосование за пропуск ночи**

Статус: исходники версии 0.1.0 опубликованы. Java 21 · Paper 1.21.11.

[Репозиторий и инструкция](https://github.com/kairvexcrypto/SleepVote) · [Каталог](CATALOG.md)

## Реализовано

- Отдельное голосование для каждого мира.
- Голоса через кровать и команду без двойного подсчёта.
- Пересчёт участников, порога и стабильный обратный отсчёт.
- Bossbar с состоянием голосования.
- Сохранение и восстановление исходного значения gamerule, включая восстановление после сбоя.
