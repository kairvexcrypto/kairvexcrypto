# Плагин не запускается: с чего начать

Красное название плагина — следствие, а не диагноз. Начните с журнала запуска: найдите первое сообщение об ошибке этого плагина, затем прочитайте весь связанный блок, включая строки `Caused by`.

1. Сохраните полный журнал запуска до любых изменений.
2. Выпишите точные версии ядра, Java и плагина.
3. Проверьте, установлены ли заявленные зависимости.
4. Сопоставьте ошибку с последним изменением: обновлением JAR, конфигурации или окружения.
5. Повторите запуск на копии сервера с минимальным набором необходимых зависимостей.

Последняя строка исключения не всегда объясняет причину. Например, ошибка загрузки класса может быть связана с отсутствующей зависимостью, а не с повреждением всего сервера. Не удаляйте папку данных наугад: вместе с настройками там могут храниться прогресс и предметы игроков.

**Проверка результата:** плагин включается после полного перезапуска, а его основная команда выполняется без новой ошибки.
