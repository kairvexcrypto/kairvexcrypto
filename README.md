## Что можно обсудить со студией

- Разработку плагина по техническому заданию.
- Предметы со способностями, талисманы и RPG-механики.
- Меню, команды, права доступа и интеграции.
- Диагностику ошибок и доработку существующих механик.
- Инструкции по установке и настройке.

## Как строится проект

Сначала фиксируем версию сервера, зависимости и поведение механики. Затем описываем команды, настройки и критерии приёмки. После реализации проверяем обычные сценарии и сбои: повторные клики, полный инвентарь, перезапуск, выход игрока и недоступность внешнего сервиса.

## Каталог

В каталоге **70 концептов плагинов** по семи направлениям. Это предложения для будущей разработки, а не список выполненных заказов. Здесь нет вымышленных клиентов, отзывов или показателей нагрузки. Исходники и готовые JAR в этот комплект не входят.

Для реальных кейсов предусмотрен [шаблон](CASE-TEMPLATE.md): задача → реализация → проверка → подтверждение результата.
