# Сервер лагает: сначала измерение

Добавление памяти не объясняет, почему сервер тормозит. Сначала выясните, когда возникает проблема: во время исследования мира, массового боя или работы конкретной механики.

При доступном spark запустите `/spark profiler start --timeout 300` во время проявления лагов. Сохраните ссылку на отчёт, число игроков и описание происходившего. Профиль пустого сервера может не показать причину вечерних задержек.

Меняйте по одному фактору и повторяйте тот же игровой сценарий. Иначе невозможно понять, какое изменение помогло. Большая доля метода в профиле сама по себе ещё не доказывает ошибку плагина: важны контекст и время выполнения.

**Проверка результата:** повторный замер при сопоставимой нагрузке показывает улучшение, а игровая механика продолжает работать.
