# После изменения конфига всё сломалось

Сначала верните сохранённую рабочую копию и убедитесь, что проблема действительно связана с изменением файла. После этого переносите изменения небольшими частями.

Проверяйте не только синтаксис YAML, но и ожидаемые типы. Список, строка и число — разные значения. Синтаксически правильный документ всё равно может содержать неизвестный ID предмета или недопустимое значение.

Сообщение с номером строки помогает найти область ошибки, но виноват может быть отступ выше. Не отправляйте полный конфиг в публичную жалобу, если в нём есть пароли или токены.

**Проверка результата:** настройка читается без ошибок и меняет именно нужное поведение. Если команда перезагрузки конфигурации у плагина не предусмотрена, используйте обычный перезапуск сервера.
