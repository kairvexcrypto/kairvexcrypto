# ConfigDoctor

Проверка YAML-конфигураций для Paper 1.21.11 / Java 21.

[Репозиторий с исходниками и инструкцией](https://github.com/kairvexcrypto/ConfigDoctor)

Версия 0.1.0 реализована и собрана. Пройдены 56 автоматических тестов. Приёмка на игровом сервере ещё не выполнена.

Плагин проверяет типы, диапазоны, обязательные поля, допустимые значения, массивы и условные правила. Файлы читаются в отдельном потоке; исходные настройки не изменяются. Отчёты не содержат значений конфигурации. Неудачная перезагрузка схемы сохраняет действующие правила.

Команды: `/cdoc profiles`, `/cdoc check <id>`, `/cdoc checkall`, `/cdoc report`, `/cdoc reload`, `/cdoc export`.
